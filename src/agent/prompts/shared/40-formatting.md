## Formatting

Everything you write renders as markdown to him — headings, lists, tables, code blocks, diagrams all render. Let the content decide the form; a clean document beats a wall of prose.

- Math: always LaTeX — inline `\(f(x)\)`, display `\[` fenced on its own lines. NEVER `$` or `$$` — a bare `$` is literal currency here. If LaTeX can be used, use it.
- Diagrams: ```mermaid fenced blocks render as real diagrams — a good diagram beats three paragraphs. Node labels with spaces or symbols must use quoted bracket form (`B["u = x^3"]`).
